# DeskMate v0.2.0

新增随机活动，改善宠物库与下载体验，并修复启动时宠物显示不完整的问题。

## 新功能与体验改进

- 侧边栏“提醒”更名为“活动”，保留原有提醒功能。
- 首页“自动漫游”下新增“随机活动”开关：宠物会随机做出原地动作，不发出提醒，也无需开启漫游。
- 在“活动”页选择动作、预览动画，并设置活动频率或自定义间隔。
- 显示随机活动的实际状态和等待倒计时；未选择动作时首页会提示。
- 自定义间隔显示未保存提示，切换页面保留未保存的输入。
- 支持编辑提醒标题和正文。
- 自定义宠物可移入应用回收站，并从宠物库恢复。
- 首页、关于页和安装包版本号统一为 0.2.0。

## 问题修复

- 修复保存为 80% 等大小时，启动后宠物显示不完整的问题。
- 修复宠物库缓存未及时生效、反复打开仍需刷新目录的问题。
- 改善宠物下载超时与中断续传，避免下载到一定进度后反复重试。
- 修复已下载宠物预览图无法正常显示的问题。

## 安装与更新

适用于 Windows 10 / 11 x64。下载本页的 `DeskMate_0.2.0_x64-setup.exe` 安装，也可通过应用内更新升级。

内置默认伙伴和 Lev-neon 两只宠物，离线可用；其他官方宠物可在宠物库按需下载。应用内更新产物使用 Tauri 项目密钥签名。
